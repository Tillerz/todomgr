## What's new

- **Themes.** Six looks to choose from under Settings → Theme (or "Theme:" in the command palette): Default, Modern, Pastel, Fantasy (parchment and ink), Sci-fi (cyan glow) and High contrast. Each has a light and a dark version, and all use fonts that come with your system.
- **The browser tab shows what matters now.** You see it from any other tab: a running timer counts down in the title (`⏱ 12:34 · Write chapter 4`), a reminder that pops up shows its name, otherwise the number of overdue todos (`⚠ 3 overdue`) or the next todo due today with its time (`📅 14:00 Call Anna`).
- **Quick add prefixes.** Start with `i:` (or `?`) for an idea, `p:` for a project, `r:` for a reminder or `t:` for a todo. A `p:` project goes to the top level instead of the Inbox. Works on the command line and over MCP too.
- **Bigger command palette.** New commands: new idea, go to Inbox, your saved views, collapse / expand all, hide done, hide tags, enable notifications, and edit notes, print list or copy the ID of the selected entry. Commands show their keyboard shortcut.
- **Edit notes from the tree.** Move through the tree with the arrow keys and press Alt+Enter: the notes open in the large editor, ready to type, even when the detail panel is closed. The row tooltip says so.
- **Day plan details.** Click the day plan bar in Today to see which entries take the time and why: overdue or due today with the open estimate, or an event with its hours. Click an entry to open it.
- **Daily pace.** A todo with units progress and a deadline shows how much is left and how much per day you need: "5,500 words left · 197 words per day for 28 days, until 30 Nov". The tree and Today show it after the name, too. Good for writing challenges, such as a novel in a month.
- **Background events.** An event can now be marked as not blocking time: untick *Blocks time in the day plan*, for example for a month-long writing challenge. Today's day plan then leaves it out. Calendar files call this "free" time, and import and export keep it.
- **Keyboard shortcuts, grouped.** The help window (`?`) and a new README section list all keys in groups.

## Fixes

- Durations are rounded to whole minutes first, so "4h 60m" now shows as "5h".
- Esc now closes the help window, and the tree no longer reacts to keys while it is open.
