## What's new

- **Notes in Markdown or BBCode.** Notes now support full GitHub Markdown (tables, code blocks, `> [!NOTE]` boxes). Switch an entry to BBCode to write World Anvil style: `[b]`, `[h1]`, `[quote]`, `[spoiler]`, `[url:…]`, `[icon:…]` and more. Notes open as a formatted preview.
- **Import CSV and calendar files.** Bring in tasks and events from Outlook, Google, Apple, Thunderbird or Excel (⋯ → Import CSV / calendar…). Entries are added to a new project; nothing is replaced.
- **Printable list.** Right-click an entry → *Print list…* prints it with everything below it, or saves it as a PDF.
- **Tag icons.** Entries with tags such as `#meeting`, `#stream` or `#nsfw` show an icon. Choose your own under Settings → Tag icons.
- **Better multi-select.** Shift+click selects a range. With several entries selected, the right-click menu can now set the status, remove a tag and add a person.
- **Notes at a glance.** A page icon shows which entries have notes; hover it to read the first lines.
