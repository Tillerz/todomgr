## What's new

- **More ways to repeat.** Repeat every N days, weeks, months or years (every 2 weeks, every 4 weeks…), or monthly on chosen weekdays, such as the 1st, 3rd and 5th Friday or the last Sunday. Pick *Custom…* in the Repeat field. Calendar import and export understand these rules too.
- **Events with an end.** Reminders can have an end time: "Sat 19:00–21:00" or "5–7 Dec". Today lists an event on every day it runs, and moving the start moves the end along. Calendar import and export include the end.

## Fixes

- With *Hide done* on, you can collapse and expand branches again.
- Typing a date with the keyboard no longer triggers errors or saves half-typed years.
- Date and time fields in the detail panel are no longer cut off; the time moves below the date when space is short.
- A change made exactly while the program shuts down is no longer written after the data store is closed.
