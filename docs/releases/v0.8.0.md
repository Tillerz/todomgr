## What's new

- **Todos that follow an event.** A todo can follow a reminder or event: detail panel → *After an event*, with a number of days. It waits until the event has ended (a clock icon, not on Today), and is then due on the event's last day plus that many days. When you finish it and the event repeats, it waits for the next time. Example: a session diary that is due 8 days after each game night. When you move the event, its todos move with it.
- **Attachments you can open.** Drop a file or a mail (from Thunderbird or Outlook) onto an entry, and the app keeps a copy in `data/files/` (up to 10 MB per file). Click it to view it: text files as text, mails with From, To, Date, Subject, the text and the names of attached files. Other files can be downloaded. A mail dragged from Thunderbird now gives one link instead of two. Note: backups and the JSON export do not include `data/files/`, so copy the whole data folder to keep them.
- **Every 2nd or 3rd month on a weekday.** Custom repeat → *Every [N] month(s) on the* … for example the 1st Friday of every 2nd month (`repeat:2m:1fr` in quick add). Calendar export and import understand it too.
- **Sort sub-items.** Right-click an entry → *Sort sub-items* by name, priority or date. *Undo* brings the old order back.
- **Project tags.** A new button next to *Hide tags*: the tag list then shows only the tags of the selected entry's top-level project, for example *Writing*. A tag you filter by always stays in the list.
- **Full page width.** Settings → Appearance → *Full page width* lets the tree and the pages use the whole window on wide screens.
- **More in the right-click menu:** add and remove people, for one entry and for several selected entries, and remove a tag from a single entry.
- **More icons, easier to find.** 12 new icons (award, bookmark, book-open, credit-card, headphones, layout, list, pen-tool, printer, save, settings, share), plus trash and moon. Both icon pickers (project icon and Settings → Tag icons) have a filter field and show the icon names on mouse-over.
- **New demo data.** Settings → *Load demo data* now gives three example areas, *Personal*, *Worldbuilding* and *Writing*, with a manuscript, calls with an editor, a trip, game nights and more. Together they show every feature of the app.
- **Tidier Settings.** The backup list and the tag icons are folded behind *Show backups* and *Show tag icons*.
- **Notes are not lost when the program stops.** What you type into a note is also kept in the browser until the program has saved it. Close the tab, or stop the program, and the next page load puts the text back. If the notes were changed somewhere else in the meantime, the page shows both texts and asks which one to keep.

## Fixes

- **No more "wrong token" errors when you come back to the app.** Two copies of the app at the same address (for example a test copy and your real one) used the same login cookie, so opening one logged the other out. Each data folder now has its own cookie, and the page repairs a lost login by itself. If the program at the address now uses a different data folder, the page does not save into it and asks you to reload. Devices that are logged in stay logged in.
- Removing a tag in Settings → Tag icons closed the whole Settings window. It could also dismiss a waiting reminder without showing it.
- When you filtered by a tag and then removed that tag from every entry, the list stayed empty. The filter now goes away with the tag.
- A todo with a deadline that you change into an event now takes the deadline as its start, and the deadline is cleared.

## For people who build the app

- All defaults for a new install (port, backup interval, LAN access, MCP, calendar subscription, theme, font, row height, work day, tag icons and more) are in one file, `app/defaults.go`.
- Every push to GitHub builds the app for all systems and runs all tests.
