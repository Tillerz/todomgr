## What's new

- **Next 7 days.** A switch at the top of Today shows tomorrow and the 6 days after it, day by day: the open todos due and the reminders on each day. A repeat shows on every day it comes up, and a todo with a daily pace (such as a word goal with a deadline) shows on every day until its deadline, with the words per day.
- **Font and text size.** Settings → Appearance has a font list and a font size slider. The list only shows fonts that are installed on the computer that opens the page.
- **Notifications in Settings.** Settings shows if desktop notifications are allowed, with a button to allow them and a hint if the browser blocks them.
- **Notes: double-click to edit.** Notes with text show as a preview. Double-click the preview to edit, and click outside the text to see the preview again. The Edit / Preview button is gone.
- **More icons.** 47 new icons for projects and tags, for example archive, box, folder, scroll, castle, swords, feather, rocket, git, party and ticket.
- **+1h for events.** The new *+1h* button next to *Ends* sets the end of a reminder to one hour after its start.
- **Import again without duplicates.** A CSV or calendar import skips entries that are already there (same kind, name, start, end and deadline). Import an updated file again and you only get the new entries. Entries without any date are always added.
- **Neutral wording.** The project link is now called *Project URL*. *Load demo data* and *Enable notifications* moved out of the ⋯ menu into Settings.

## Fixes

- Entries inside a project in the trash no longer show in Today, the day plan or entry links, and their reminders no longer pop up or post to Discord.
- Entries inside a project in the trash can no longer be edited, moved or created into. Restoring a single entry whose old parent is in the trash puts it at the top level, so it does not stay hidden.
