## What's new

- **Notes are not lost when the program stops.** What you type into a note is also kept in the browser until the program has saved it. Close the tab, or stop the program, and the next page load puts the text back. This also works when a phone closes the tab in the background, for example on a weak Wi-Fi. If the notes were changed somewhere else in the meantime, the page shows both texts and asks which one to keep.
