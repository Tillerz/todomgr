## What's new

- **The Project page.** A new tab (key `4`) shows one project at a glance: the words done and left, the words of today, what each day needs to finish in time, your speed and the day you will be done, and bars for the last 14 days. Below are its chapters and other goals with a tick box, a bar, the count and a field to log words. The chart fills as you log progress: the app keeps the amount of each day from this version on.
- **Lists show the project.** Each row on *Today* and *Next 7 days*, and each writing goal, starts with a label of its project, in the project's colour and with its icon. A click on the label opens the Project page.
- **Quick add from every page.** The new **+ Add** button in the header (a round **+** at the bottom right on a narrow screen) or the key `N` opens the Quick add window on *Tree*, *Today* and *Stats*. You stay on the page you are on; the message has *Show* to jump to the new entry. The list *To* says where the entry goes: the Inbox, the selected entry, or one of your projects. The field above the tree, *+ Project* and *+ Reminder* are gone: start the line with `p:` for a project or `r:` for a reminder.
- **Log words right on Today.** Each writing goal on *Today* has a small field: type `+500` (or the new total) and press Enter. No window opens. A goal with a card at the top is no longer listed a second time below.
- **Growing pictures, drawn again.** The **journey** has a walker with a pack; what the walker has passed gets its colours, a camp, the bridge and a banner mark the quarters, and the sun moves across the sky. After you log progress, the walker walks to its new place. The **book** is an open book now: lines of text fill the left page, then the right one, a ribbon comes at the half, and at 100 % it is a bound book with your title. In both, what you did today is drawn in the entry's colour.
- **A shorter detail panel.** Fields without a value (color, picture, after an event, in charge, location, depends on, time, links) are left out. The **More fields** bar below the notes shows them for that entry. *Settings → Always show all fields in the detail panel* brings the full panel back.
- **A tidier tree page.** *Collapse all*, *Expand all*, *Hide done*, *Hide tags* and *Project tags* are in one **View** menu. The Quick add words (`#tag`, `due:`, `repeat:` …) show in the Quick add window.
- **Pictures in the file viewer.** A click on an attached PNG, JPEG, GIF or WebP file shows the picture. Before, it could only be downloaded.
- **Remove unused attachments.** *Settings → Data → Remove unused attachments* deletes the files in `data/files/` that no entry uses any more. The button shows how many there are, and its tooltip lists them. Entries in the trash count as in use, and files added in the last hour are left alone.
- **A new data folder starts with its Inbox.** Also after *Start with empty data*.
- **Export and import are in one place.** They are in the ⋯ menu at the top right (and in the command palette), and no longer a second time in Settings.
- **Narrow screens:** the command palette and the light / dark switch moved into the ⋯ menu, to make room for the fourth tab.
- **Settings: AI and MCP server are at the end**, before *About*, so the settings for every day come first.

## Fixes

- **Monthly and yearly repeats at the end of a month.** A todo on 31 January now repeats on 28 February, not on 3 March, and a yearly one on 29 February goes to 28 February. Before, the date ran over into the next month and stayed there.
- **Quick add: a time without a day.** `Call Anna at:14:00` is due today at 14:00, or tomorrow when that time has passed. Before, the time was dropped.
- **The timer's alarm stops at the first click or key press**, and when the timer is closed or made longer in another window. Before, it could go on for a minute after the window was closed.
- **A cancelled sub-item can finish its parent.** When the last open sub-item is cancelled and the others are done, the app offers *Mark parent done*, as it does when the last one is finished.
- **A project with goals in different units** (words and characters) counts the unit with the largest goal for its picture. Before, it took the first one it found.
- **The program starts again after the computer (or WSL) was shut down without stopping it.** The lock file now holds a boot id, so a lock from before the restart is taken over even when its process number is in use again.
- **After a restart of the program, a page that is behind refreshes before it saves**, so it cannot overwrite a newer change.
- **`todo mcp` always answers.** When the program refuses a request or is not running, the AI tool gets an error answer instead of waiting.
- An upload that is not valid JSON now says so, instead of "the file is larger than 10 MB".

## Safety

- **Content-Security-Policy.** The app page and the login page now tell the browser to run only the program's own script, named by its fingerprint. A script that gets into the page another way, for example through a note, does not run.
- **Discord posts only go to Discord.** The webhook of a project is checked again right before each post, also when it came in through a JSON import. AI tools (MCP) can no longer set a webhook.

## For people who build the app

- Entries with progress in units keep `progHist` (`{"YYYY-MM-DD": amount of that day}`, 400 days), written by the page and by `prog` changes through the API.
- New default in `app/defaults.go`: `detailFull` (false) for *Always show all fields in the detail panel*.
- New API: `GET /api/files/unused` and `POST /api/files/unused` (list and remove unused attachments), `GET /api/files/{key}/image` (a stored picture). `GET /api/files/{key}/view` can answer `kind: "image"`.
- The page must not use `onclick="…"` attributes any more: the Content-Security-Policy blocks them. Use `addEventListener`; a test checks it.
- The first line of `data/todomgr.lock` is now `pid@bootid` on Linux.
- New tests are in `app/review_test.go`; `app/testdata/recur_cases.json` has the month-end cases for the server and the page.
